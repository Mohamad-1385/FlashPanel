# 🚀 راهنمای نصب فارسی — پنل فلش

## این پروژه چیست؟
پنل فلش یک سرور پروکسی شخصیِ کامل روی پلن **رایگان** کلادفلر است: یک فایل ورکر + یک دیتابیس D1. بدون سرور، بدون دامنه، بدون هزینه.

## پیش‌نیازها
1. یک حساب Cloudflare رایگان — [dash.cloudflare.com](https://dash.cloudflare.com)
2. Node.js (نسخه ۱۸ به بالا) — برای اجرای `wrangler`
3. دو دقیقه وقت 🙂

## نصب در ۴ قدم

### قدم ۱ — دریافت پروژه
```bash
git clone https://github.com/Mohamad-1385/FlashPanel.git
cd FlashPanel
```

### قدم ۲ — ساخت دیتابیس
```bash
npx wrangler d1 create flash-db
```
دستور بالا یک `database_id` چاپ می‌کند — آن را در فایل `wrangler.toml` جایگزین `REPLACE_WITH_YOUR_D1_ID` کنید.

### قدم ۳ — گیت مخفی خودتان را بگذارید
در `wrangler.toml` مقدار `GATE` را به یک عبارت تصادفیِ شخصی تغییر دهید (مثلاً خروجی `openssl rand -hex 8`).
پنل **فقط** روی مسیر `/m/<گیت شما>` باز می‌شود — برای غریبه‌ها سایت یک استودیوی طراحی معمولی است.

### قدم ۴ — دیپلوی
```bash
npx wrangler deploy
```
تمام! پنل شما: `https://<نام-ورکر>.<زیردامنه>.workers.dev/m/<گیت شما>`

اولین ورود: رمز مدیر را تعیین می‌کنید و وارد پنل می‌شوید.

## بعد از نصب
- از «⚡ ساخت سریع» یک کانفیگ بسازید (VLESS / Trojan / SS / VMess)
- لینک اشتراک را در v2rayNG / Hiddify / sing-box ایمپورت کنید
- برای بهترین سرعت: «📡 رادار» ← اسکن IP ← گروه اپراتور خودتان (ایرانسل / همراه‌اول / رایتل / مخابرات)
- برای جمنای: گروه «🤖 هوش مصنوعی» + خروجی آمریکا/انگلیس
- برای WARP: «🛰 اندپوینت پیشرفته» — ۱۵۵ اندپوینت رسمی + اسکن زندهٔ ۲۲-پورته

## پرسش‌های رایج

**هزینه واقعی صفر است؟** بله — کل پشته روی پلن رایگان کلادفلر اجرا می‌شود. پنل طوری طراحی شده که نوشتن‌های دیتابیس ~۸۶٪ کمتر از حالت عادی باشد.

**IP ورودی از کجا بیاورم؟** از خود پنل: «📡 رادار» ← «اسکن» — رنج‌های کلادفلر را اسکن می‌کند و سریع‌ترین‌ها را برای اپراتور شما پیشنهاد می‌دهد.

**اگر پنل خطای 1101 داد؟** ربات فلش دکمهٔ «🛡 ترمیم» دارد — خودکار درمان می‌کند.
