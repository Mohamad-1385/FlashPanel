# 🤖 ربات فلش — مدیر پنل در جیب شما

ربات [**@Mohamadaghilibot**](https://t.me/Mohamadaghilibot) در تلگرام، هم‌تیمِ پنل فلش است: هر کاری در پنل می‌کنید، از تلگرام هم در دسترس است.

## امکانات

### 🎛 مدیریت پنل
- لیست همهٔ پنل‌ها + نسخه‌ها + وضعیت به‌روز بودن
- بروزرسانی تک‌پنل یا «آپدیت همه» با اطلاع‌رسانی
- ترمیم خودکار خطای 1101 و نجات پنل مسدود
- حذف ایمن پنل

### 👥 مدیریت کاربرها
- ساخت سریع: اسم + پلن → کانفیگ آماده با QR
- کارت هر کاربر: مصرف، زمان باقی‌مانده، کشور خروجی، لینک اشتراک
- تمدید، تغییر حجم، تغییر کشور، بلاک/آنبلاک، حذف
- دکمهٔ نصب یک‌لمسهٔ v2rayNG

### 🛰 اندپوینت پیشرفته (WARP)
- ساخت کانفیگ **WARP / WireGuard / AmneziaWG** با ثبت‌نام واقعی و تست زنده
- **۱۵۵ اندپوینت رسمی** — ۴۳ پورت دامنهٔ engage + ۲۸ IP کلادفلر × ۴ پورت
- هر ساخت = **کلید تازه + اندپوینت تصادفی** (برش اختصاصی هر پروتکل)
- «🔍 اسکن زندهٔ اندپوینت‌ها» — تست TCP واقعی با گزارش سریع‌ترین‌ها
- خروجی همه: **غیر ایران** (شبکهٔ جهانی Cloudflare)

### 🌍 رله‌ها
- تست پینگ واقعی رله‌های همهٔ کشورها
- جستجوی رله‌های جدید در کل جهان (کشف خودکار کشورهای تازه)
- ۲۵+ کشور خروجی: آمریکا، انگلیس، آلمان، هلند، ترکیه، امارات، سنگاپور، ژاپن، کره، هند، روسیه و…

### 🛟 پشتیبانی و گزارش
- دسته‌بندی گزارش باگ / مشکل اتصال / مشکل کانفیگ / پیشنهاد / سوال
- گفتگو مستقیم با مدیر
- آمار گزارش‌ها + دستیار هوشمند
