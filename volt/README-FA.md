# ⚡ VOLT — پنل فلش نسل Go

پنل VLESS نسل جدید — معماری سه‌لایه با سهم‌های واقعی:

| لایه | زبان | سهم | مسیر |
|------|------|-----|------|
| بک‌اند + ربات + ابزار | **Go** | ~۷۳٪ | `backend/` |
| ورکر لبه (تونل + ساب + API) | **TypeScript** | ~۲۱٪ | `worker/` |
| ظاهر میز فرمان | **Tailwind CSS** | ~۶٪ | `ui/` + `worker/src/ui.ts` |

## معماری

```
[کاربر] ──TLS/WS──▶ [ورکر TS] ──رلهٔ کشور──▶ [اینترنت]
                       │ D1 (کلیدها/تنظیمات/بریج)
                       ▼
                  [دیمن Go: voltd] ──▶ تلگرام (مدیر)
                       ▲
              [ترمینال پنل / voltctl]
```

- **voltd** (Go): ربات تلگرام + بریج D1 + مانیتور سلامت + تاریخچهٔ ساعتی + خزانهٔ AES-GCM
- **voltctl** (Go): `deploy` · `push` · `verify` (کلاینت VLESS بومی Go) · `status` · `report` · `vault`
- **ورکر** (TS): تونل VLESS با 0-RTT و UDP-DNS، پین IP ثابت، ضدتبلیغ هسته‌ای، اشتراک در base64/xjson/singbox/clash
- **میز فرمان** (Tailwind): گرافیت + ولت الکتریکی — بدون دراور و سایدبار، نوار فرمان بالا + بنتو

## ساخت

```bash
node scripts/build.js          # tsc (strict) → esbuild → Tailwind درون‌سازی
cd backend && go build ./...   # Go 1.24
go test ./...                  # ۸ پکیج تست
./bin/voltctl deploy           # دیپلوی کامل از Go
./bin/voltctl verify           # تست E2E زنده
```

## درس‌های پورت‌شده از نسل قبل (7.9.x)

- سینگ‌باکس بدون `domain_strategy` (ریشهٔ باگ Hiddify 7.9.29)
- `interrupt_exist_connections: false` در urltest
- ضربان WS ۲۵ ثانیه‌ای (پایان «درحال اتصال» تلگرام)
- Mux خاموش + 0-RTT همه‌جا
- DNS زنجیره‌ای: DoH (RFC 8484) → TCP 8.8.4.4
- پین IP ثابت با مین-هش سازگار (uid × رله)

## تغییرات

### v1.0.1 «تپش» — زنده‌شدن پینگ کانفیگ‌های لوکیشن (P181)

ریشه‌یابی کامل «کانفیگ‌های لوکیشن‌دار اصلاً پینگ نمی‌دادند»:

- **۳ ریشه:** ① ۱۲ کشور رلهٔ `proxyip.<cc>.workers.dev` داشتند که خودش پشت کلودفلر است — ورکر به CF وصل نمی‌شود → تونل همان لحظه می‌میرد ② `cp.cloudflare.com` (URL تست پینگ v2rayNG) در فهرست دامنه‌های CF نبود → دیال مستقیم → مرگ ③ `connect()` تنبل بود (رلهٔ مرده «موفق» می‌شد) و کلید لوکیشن‌دار همهٔ ترافیک را از رله می‌گذراند در حالی که رله‌های کمونیتی فقط SNI کلودفلر را پاس می‌دهند → گوگل/یوتیوب مرده
- **کاتالوگ صداقت:** ۱۴ کشور قلابی/مرده حذف (tr، ae، gr، cy، es، at، ro، rs، az، am، ge، kz، tw، nl)؛ ۴ کشور واقعی جدید (lv، md، me، th) — همهٔ ۲۴ کشور با تست تونل واقعی تأیید شدند: **۲۴/۲۴ پینگ http + ۲۴/۲۴ پینگ https + گوگل مستقیم در همه‌جا**
- **تشخیص CF-hosted عمومی:** DoH (cloudflare-dns.com → dns.google) + ۱۵ رنج IPv4 کلودفلر + میان‌بر دامنه‌ها + فهرست skip غول‌های غیرCF (درس شهاب فلش — میزبان‌های تازهٔ یوتیوب بدون DoH)
- **دیال تأییدشده:** هر رله با `opened` واقعی TCP تأیید می‌شود (درس dialVerified فلش) — رلهٔ مرده دیگر «موفق» نیست
- **مسیر جدید (مدل اثبات‌شدهٔ فلش):** رلهٔ کشور فقط برای تارگت‌های CF-hosted؛ گوگل/تلگرام/نتفلیکس مستقیم از egress ورکر؛ پورت ۸۰ CF فقط با رله‌های اختصاصی دوپورت تأییدشده (ایتالیا/برزیل) — زنجیرهٔ قطعی بدون بخت‌آزمایی استخر
