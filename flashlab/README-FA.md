# ⚡ فلش‌لب FLASHLAB — پنل آزمایشی فلش، نسل Go

پنل VLESS آزمایشی پروژهٔ فلش — معماری سه‌لایه با نقش‌های جدا:

| لایه | زبان | نقش | مسیر |
|------|------|-----|------|
| بک‌اند + ربات + ابزار + رادار | **Go** | ۱۰۰٪ نقش‌های سرور | `backend/` |
| ورکر لبه (تونل + ساب + API + QR) | **TypeScript** | ۱۰۰٪ نقش‌های لبه | `worker/` |
| ظاهر میز فرمان | **Tailwind CSS** + قالب HTML | ۱۰۰٪ ظاهر | `ui/` + `worker/src/ui.ts` |

نسخه: `1.0.0 «صاعقه»` — هستهٔ لبه: `FLASHLAB-GO/1.0`

## معماری

```
[کاربر] ──TLS/WS──▶ [ورکر TS] ──رلهٔ کشور (CF-hosted)──▶ [اینترنت]
                       │ D1 (کلیدها/تنظیمات/رادار/بریج)
                       ▼
                 [دیمن Go: flashd] ──▶ تلگرام (مدیر)
                       ▲
          [ترمینال پنل / flashctl]
```

## قابلیت‌های نسل «صاعقه»

- **رادار همزمان رله‌ها** — هر ۱۰ دقیقه، همهٔ رله‌های ۲۴ کشور با گوروتین‌ها اسکن می‌شوند؛ هندشیک واقعی TLS با SNI کلودفلر از دل رله (نه فقط TCP). نتایج در D1؛ لوکیشن کاملاً مرده → هشدار فوری تلگرام.
- **توربو** — کلیدهای توربو رله‌ها را به ترتیب سرعت واقعیِ رادار امتحان می‌کنند (تست زنده: هنگ‌کنگ توربو ۶.۶ MB/s در برابر ایتالیا ۱.۷ MB/s).
- **تست سرعت واقعی** — دانلود واقعی از دل تونل (speed.cloudflare.com از مسیر رله) با کلاینت VLESS بومی Go — `flashctl speed <uuid>` و `/speed <uuid>` در ربات.
- **QR اسکن‌پذیر** — هر کلید QR سمت سرور (SVG) دارد؛ در v2rayNG مستقیم اسکن شود.
- **فرگمنت سیم‌کارت** — `?frag=mci|irancell|rightel|fixed` (درس 7.9.29).
- **پین IP ثابت** — مین‌هش سازگار (uid × رله)؛ پایان نوسان IP.
- **0-RTT + ضربان ۲۵ ثانیه** — پایان «درحال اتصال» تلگرام.
- **مسیر اثبات‌شده** — CF-hosted از رله، غیرCF مستقیم از egress ورکر (درس P181) + گارد ریسک هندشیک (فریم‌های مسابقه‌جو به pendingQ می‌روند).

## ساخت

```bash
node scripts/build.js          # tsc (strict) → Tailwind → esbuild
cd backend && go build ./...   # Go 1.24
go test ./...                  # ۹ پکیج تست
./bin/flashctl deploy          # کل دیپلوی از Go (D1 + ورکر + رمز + ساب‌دامین)
./bin/flashctl verify          # E2E زنده (کلاینت VLESS بومی Go)
./bin/flashctl radar           # اسکن همزمان زنده + گزارش فارسی
./bin/flashctl speed <uuid>    # تست سرعت واقعی
./bin/flashd                   # دیمن: ربات + بریج + رادار + مانیتور
```

## دستورهای ربات (پل تلگرام)

`/status · /stats · /keys · /newkey · /sub · /loc · /ipmode · /turbo · /renew · /delkey · /radar [live] · /best · /speed · /report · /trend · /help`

## درس‌های پورت‌شده (نسل‌های قبل)

- کاتالوگ صداقت: ۲۴ کشورِ تست‌شدهٔ واقعی (۱۴ کشور قلابی P181 حذف شدند)
- `dialVerified` — رلهٔ مرده دیگر «موفق» نمی‌شود
- `isCfTarget` عمومی: رنج‌های CF + DoH + skip غول‌های غیرCF
- سینگ‌باکس بدون `domain_strategy` (ریشهٔ باگ Hiddify) + `interrupt_exist_connections: false`
- پورت ۸۰ CF فقط با رله‌های دوپورت تأییدشده
- رمز پنل = کد ادمین (یک راز برای پنل و ربات — در دیپلوی Go تولید و در D1 کاشته می‌شود)
